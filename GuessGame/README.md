# 🎯 Guess Game (C# Console Project)

A simple but well-structured number guessing game built with C# and .NET 8.

---

## 🚀 Features

- Random number generation (1–100)
- User input validation
- Hint system (higher / lower)
- Attempt counter
- Player system
- Best score tracking

---

## 🧠 Concepts Used

- Object-Oriented Programming (OOP)
- Classes and Objects
- Encapsulation
- Loops & Conditions
- Input validation

---
