# 🎯 Guess Game (C# Console Project)

A simple but well-structured number guessing game built with C# and .NET 8.
This project demonstrates object-oriented programming (OOP), clean code structure, and basic input handling.

---

## 🚀 Features

- Random number generation (1–100)
- User input validation
- Hint system (higher / lower)
- Attempt counter
- Player system
- Best score tracking

---

## 🧠 Concepts Used

- Object-Oriented Programming (OOP)
- Classes and Objects
- Encapsulation
- Loops & Conditions
- Input validation

---

## ▶️ How to Run

Clone the repository:

```bash
git clone https://github.com/YKdevx/learning-projects.git
```
Navigate to the project folder:
```bash
cd GuessGame
```
Run the application:
```bash
dotnet run
```
