# 🎓 Student Database - C# Console Application

A console-based student management system built with C# and .NET 8.

---

## 🚀 Features

- Add student with subject scores
- Automatic average calculation
- List all students
- Filter students by performance (Low / Medium / High)
- Color-coded output in console
- In-memory data storage (Dictionary)

---

## 🧠 Concepts Used

- Object-Oriented Programming (OOP)
- Dictionaries (Nested data structures)
- Methods & Separation of concerns
- Input validation
- Console UI design

---

## ▶️ How to Run

Clone the repository:

```bash
git clone https://github.com/YKdevx/learning-projects.git
```
Navigate to the project folder:
```bash
cd Students
```
Run the application:
```bash
dotnet run
```
