# 🔐 Login System - C# Console App

A simple login and registration system built with C# and .NET 8.

---

## 🚀 Features

- User registration
- User login validation
- In-memory user storage
- Menu-based console UI
- OOP structure

---

## 🧠 Concepts Used

- Object-Oriented Programming (OOP)
- Classes & Objects
- LINQ (Any)
- List collections
- Input handling
- Menu-driven console app

---

## ▶️ How to Run

Clone the repository:

```bash
git clone https://github.com/YKdevx/learning-projects.git
```
Navigate to the project folder:
```bash
cd LoginSystem
```
Run the application:
```bash
dotnet run
```

---

## 🎯 Purpose

This project was created to practice OOP principles, data handling, and basic authentication logic in C#.
